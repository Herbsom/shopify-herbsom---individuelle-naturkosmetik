# Referenzgetreue Bildintegration der Startseite

## Quelle

Die Bildstruktur wurde aus der angehängten Aufgabe [„Neue Website für herbsom.de mit Aesop- und Dr Joseph-Look“](https://manus.im/share/YSAhJ3awNcnCc3DDT8f5Ku) abgeleitet. Maßgeblich ist die dort gespeicherte Startseitenkomponente.

## Vergleichsergebnis

| Startseitenbereich | Referenzintegration | Zielintegration in Herbsom |
|---|---|---|
| Hero | Vollflächiges Hintergrundbild mit `bg-cover bg-center`, `h-screen`, sanftem Creme-Verlauf | Bestehendes Herbsom-Hero-Motiv in derselben Einbindung beibehalten |
| Philosophie | Linke Bildhälfte in einer zweispaltigen, dunkelgrünen Sektion, `h-72` mobil / flexible Höhe ab Desktop | `HOME_IMAGES.ingredients` |
| Hauttest | Portrait im Verhältnis `3:4`, `bg-cover bg-center`, neben dem Formular | `HOME_IMAGES.ritual` |
| Editorial / SPF | Bild im Verhältnis `4:3`, `bg-cover bg-center`, mit „Neu“-Label | `HOME_IMAGES.texture` |
| Story-Sektion | Rechte Bildhälfte in einer zweispaltigen, hellen Sektion, `h-72` mobil / flexible Höhe ab Desktop | `HOME_IMAGES.products` |
| Abschließender CTA | Vollflächige, halbhohe Texturfläche mit hellem Overlay | `HOME_IMAGES.texture` |

Für die sichtbare Herbsom-Storefront werden ausschließlich bereits geprüfte, markenneutrale Projektassets verwendet. Die Referenz bestimmt damit Platzierung, Zuschnitt und responsives Verhalten, nicht die Nutzung fremder sichtbarer Markenkennzeichen.
